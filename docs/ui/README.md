# Sensei++ UI design documentation

Start with [SPA Design Guidelines](Sensei-SPA-Design-Guidelines.md) when designing or implementing web screens. The selected baseline is **Coastal + Coastal Night with cobalt primary actions**, using **React + shadcn/ui + Base UI**.

| Document | Purpose |
| --- | --- |
| [SPA Design Guidelines](Sensei-SPA-Design-Guidelines.md) | Concrete light/night palette, typography, spacing, responsive shell, component states, accessibility, and adoption rules. |
| [Visual Identity and UI Guidelines](Sensei-Visual-Identity-and-UI-Guidelines.md) | Living Campus personality, illustration language, product distinctions, and shared identity. |
| [Codex UI Implementation Handoff](Sensei-Codex-UI-Implementation-Handoff.md) | Workflow for implementing and verifying the reusable kit and authorized screens. |
| [UI Demo](Sensei-UI-Demo.md) | Running the standalone reflection/gallery reference, current code locations, and verification limits. |
| [SPA Design Implementation](Sensei-SPA-Design-Implementation.md) | Applied routes, shared theme sources, verification results and screenshots of the working application. |

Product requirements govern behavior and scope. The SPA guidelines govern concrete web design choices where older exploratory directions differ. Other demo themes and retired screenshots remain exploration history. Character specifics and native application design remain deferred.
